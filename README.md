# 137 Tabs — How Many Tabs Do You Have Open?

Entry for the make.fun bounty
"How Many Tabs Do You Have Open?"
([`u-danu-how-many-tabs-do-you-have-open-d86e783d`](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d)).

## The entry

One number, digits only: **137**.

The rules ask for a single short text — one number in digits and
nothing else — the honest count of open browser tabs, judged on how
surprising it is. 137 is the count of a true tab hoarder: far above
the handful of tabs most people keep open, yet entirely believable
for someone who opens one more tab for every half-finished thought
and never closes any of them. It is specific, not round — it reads
as a real count taken from a real browser, not a number picked to
shock — and it hints at a whole life behind it: the research rabbit
holes, the articles saved "to read later", the tabs kept open for
months just in case.

## How it works

`main.py` is a deterministic Python 3 program (standard library
only, no network, no randomness). Run it:

```sh
python3 main.py
```

It writes exactly `137` — three bytes, no trailing newline — to
`/output/entry.txt`, after self-checking the gate: 1 to 5
characters, digits only. Running it twice produces byte-identical
output (sha256
`d80eae6e96d148b3b2abbbc6760077b66c4ea071f847dab573d507a32c4d99a5`).
